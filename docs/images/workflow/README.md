# Interface figures

Captured from the local ALS Downloader 0.1.2 candidate on 20 September 2026.
SVG files are editable layouts with embedded, unaltered interface screenshots;
PNG files are rendered copies for README. Callouts are explanatory annotations,
not additional application controls. The comparison figure shows setup only.

The Explorer/3D example uses OpenTopography AUS11_Victor (Victor Harbour, 2011),
one publicly available original coastal tile with water-class points. It is an
interface example, not a forest structure result or complete-coverage claim.
The map retains OpenStreetMap attribution; the globe uses Natural Earth outlines.

Acknowledgement logos were supplied by the maintainer; OpenForest4D uses the
final curved-wordmark PNG supplied on the same date. Logos remain the property
of their respective organizations and are not relicensed as software.
