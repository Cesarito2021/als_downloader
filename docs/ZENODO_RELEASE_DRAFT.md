## Description

ALS Downloader is an R package and Shiny application for finding airborne and
UAV LiDAR data by study area, inspecting source metadata and downloading original
files. It includes bounded point-cloud previews, visual comparisons between
source campaigns or a source and a local LAS/LAZ file, figure exports and PDF
study reports. Community Zenodo contributions use coverage polygons and file
links and require maintainer approval before entering spatial searches. Source
data remain with their providers under their original licences; the software
does not redistribute these datasets or calculate environmental change.

Developed within OpenForest4D, funded by NSF awards **2409885, 2409886 & 2409887**.
